## 📝 Descripción del Proyecto
Este repositorio contiene el núcleo funcional y las mecánicas base para **Cepa: The Return to Friedland**, un videojuego de plataformas en 2D inspirado en la jugabilidad clásica de Kirby. Este avance se enfoca en la arquitectura del código, la estabilidad de las físicas y la toma de deciciones de arquitectura lógica en el diseño del videojuego, utilizando *placeholders* visuales temporales obtenidos de la Unity Asset Store para garantizar una ejecución sin errores.
